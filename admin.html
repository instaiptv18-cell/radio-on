Conexão com o GitHub

Configurar (só precisa fazer uma vez)

Como criar o token: GitHub → foto do perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Escolha só o repositório da rádio e, em Permissions, Contents: Read and write. O token fica guardado só neste navegador; não o mostre a ninguém.

Se preferir não usar token: aperte Baixar config.json e, no GitHub, abra o repositório → Add file → Upload files, e envie o arquivo (ele substitui o antigo).
